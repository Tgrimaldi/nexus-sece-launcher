# NEXUS SECE Launcher

Launcher PWA públic per instal·lar accessos NEXUS Manteniment amb icona pròpia. No conté dades, fulls ni contrasenyes de SECE.

## Compatibilitat Google multi-compte

Els accessos cap a Google Apps Script utilitzen el format `/a/*/macros/s/...` per evitar el problema conegut en què navegadors amb diversos comptes Google poden reescriure `/macros/s/...` a `/macros/u/1/s/...` i mostrar l'error de Google Drive «No se puede abrir el archivo en estos momentos».
